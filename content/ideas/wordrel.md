# 词语

从语言哲学来的思考。

## 范畴论

从结构主义角度来看，重要的不是单个词，而是词之间的关系。每个词的语义都由词在网络中的关系。
从数学的范畴论来看，这是考虑一个以词元为 object 的范畴。词之间的关系应该不唯一。

目前对 attention 机制的解释是，用 QKV 来移动词向量，让它的语义发生变化。
但是如果一开始就把词之间的关系当作基础呢？这样直接就不需要考虑词向量是否在一个语义的正确空间。
用 $\mathrm{Hom}(A,B)$ 取代词语的嵌入向量的地位，而且也许 $\#\mathrm{Hom}(A,B)\neq 1$

似乎可以把语言的某些小结构提出来，一组词语的关系图抽象出来，和另一组词的图比较。例如不同语言的1-9的结构，或者也许把隐喻提出来。

> 与其先定义向量 `[国王, 王后, 男性, 女性]` 然后考虑差值 `[国王]-[王后], [男性]-[女性]`的特征含义，不如直接考虑把差值 `[国王 -> 王后], [男性 -> 女性]`。

这时候和词向量一个向量相比，对应的数据结构应该类似于

```
{
    "source": "king",
    "target": "queen",
    "map": "the something need to be trained",
    "id": "there are more than 1 map between objects"
}

```

当然一个明显的复杂度提升，是从 `N=vocab, O(N)` 到 `O(N^2)`，但是其他部分的架构简化也许能减小复杂度。  
要把训练语料做一定删减，去掉那些比较新的、过于隐晦的、过于特殊的隐喻，把那些广泛成立的关系提取出来。

另一个问题是，怎么取出要输出的词。  
这个训练过程也许不是自回归的，而是把重点放在识别结构。这甚至不必要是一个生成语言模型。 After all, why is it necessarily generating words?

## 计算语言学

另一个角度，从乔姆斯基的语言的生成特性来思考。
这里先不考虑欧陆哲学风味的意指、所指、能指，而是考虑形式语言的这个语言能力。
和之前关于[世界模型](/ideas/world)相比，限制在语言范围内的先天能力，即人类能够从语法生成语言，而不需要大量输入。

把符号主义和连接主义做一个结合。
